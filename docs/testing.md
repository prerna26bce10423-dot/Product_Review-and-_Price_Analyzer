# Testing 
## 1 . Testing approach 
the project was tested by providing different types of inputs to verify whether the review analysis , graph , and input validation work correctly .
testing was performed manually through the streamlit interface .
The performned Test cases are :

1)normal review 
2)suspicious review
3)pice history 
4)missing review 

The system does not claim that a review is definitely fake. It only identifies potentially suspicious patterns based on the rules implemented in the prototype.
The system was checked for:

- Current price
- Previous price
- Recent lowest price
- Price decrease
- Price increase
- Price trend graph
5) the application was also tested with missing inputs .
If the product name, source, or review is missing, the system displays a warning instead of performing the analysis.
 Testing Conclusion
